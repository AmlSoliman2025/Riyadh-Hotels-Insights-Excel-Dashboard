# Riyadh Hotels Insights Dashboard

This Excel dashboard visualizes insights from 55 hotels in Riyadh, Saudi Arabia. It includes pricing trends, hotel popularity, booking platforms, and ratings.

## 📊 Dashboard Highlights
- **Total hotels analyzed**: 55
- **Average price**: 492.82 SAR
- **Price categories**:
  - Luxury (≥650 SAR)
  - Mid-Range (650 > x ≥ 500 SAR)
  - Budget (<500 SAR)
- **Top hotels**: Sheraton Riyadh, Le Méridien, Fairmont
- **Popular platforms**: Booking.com, Agoda, MakeMyTrip

## 🧰 Tools Used
- Microsoft Excel
  - Pivot Tables
  - Slicers & Filters
  - Charts & Conditional Formatting
